ROBOMISIÓN LAB · VERSIÓN 61 · ARCHIVOS PARA SUBIR A GITHUB
==========================================================

OBJETIVO
Eliminar el panel «Mi progreso» y todas las referencias al panel en las páginas,
menús, buscador y misiones. Mantener las 16 misiones Maqueen Plus V2,
los ejemplos guiados y los retos Bronce / Plata / PRO.

CONTENIDO
- index.html: portada sin el botón del panel de progreso.
- misiones.html y mision.html: listado y fichas sin acceso al panel.
- simuladores.html, proyectos-pro.html y profesor-pro.html: enlaces eliminados.
- maqueen-plus.html: 16 misiones con ejemplos V60 y sin enlace al panel.
- assets/site.js: buscador global sin entrada «Mi progreso».
- assets/pro-main.js: catálogo sin XP, insignias ni página de perfiles.
- assets/maqueen-v60-alumno.js y .css: ejemplos guiados y estilos de Maqueen.

CÓMO SUBIRLO (SIN GITHUB ACTIONS)
1. Descomprime este ZIP en tu ordenador.
2. Entra en https://github.com/manuelpdb/robomision-lab
3. Usa Add file → Upload files en la rama main.
4. Sube todos los archivos y la carpeta assets, respetando su estructura.
5. Confirma con Commit changes. Sobrescribe los archivos que ya existan.
6. IMPORTANTE: GitHub NO elimina archivos antiguos por subir un ZIP.
   Para borrar de verdad la página, entra en el archivo mi-progreso.html
   en GitHub, pulsa el menú (...) → Delete file y confirma el commit.
7. Abre la web publicada y actualiza forzando Ctrl+F5.

NOTAS
- Este ZIP es la actualización manual COMPLETA necesaria para quitar el
  panel de progreso; no es una copia independiente de todas las páginas
  y recursos del sitio. Debes subirlo SOBRE tu repositorio existente.
- No borres las demás carpetas y archivos de GitHub.
- El solucionario docente no se incluye: debe permanecer fuera del sitio
  público para que el alumnado no vea las respuestas.
- Las notas y los cuestionarios de las misiones se mantienen.
- Los indicadores específicos de los laboratorios permanecen, porque
  son distintos del panel global de progreso eliminado.
- Esta actualización está basada en la copia disponible del sitio.
  Si modificaste recientemente el diseño de esas páginas en GitHub,
  haz una copia del repositorio antes de sobrescribirlas.
