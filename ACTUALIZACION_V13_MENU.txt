PARA ACTUALIZAR GITHUB DESKTOP:

2. En la carpeta del repositorio ELIMINA MANUALMENTE estos DOS archivos:

   - proyecto-final.html
3. Comprueba en GitHub Desktop que figuran como Deleted además de los archivos modificados.
4. Commit to main y después Push origin.
5. Recarga la web con Ctrl+F5 y abre el botón Menú en Inicio y en un laboratorio antiguo.

IMPORTANTE: el ZIP de actualización no puede borrar automáticamente archivos existentes del repositorio.
