FICHA 15 · Sensores avanzados

Sensor de color

Módulo para reconocer colores cercanos.

2 Inicial2 Intermedio2 PRO
01 · CONEXIÓN

Antes de programar

Conexiones y precauciones: distancia típica de reconocimiento 3–10 mm; probar alrededor de 5 mm. Función propia de ACEBOTT.

Pines del montaje: Sensor I2C con Acebott.colorDetect().

Limitación técnica: con bloques básicos no se pueden leer directamente las funciones especiales de este módulo. Las seis actividades preparan una interfaz o una simulación educativa con la micro:bit; no realizan mediciones reales del módulo.
02 · EMPEZAMOS A PROGRAMAR

Bloques

Clasificación manual

El sensor de color necesita un controlador para reconocer colores. En estas actividades los botones simulan las decisiones; no se mide ningún color real.

Pulsa «Ver bloques» (necesita conexión a Internet).

Abrir MakeCode
